
**Base URL:** `https://kovacslaci.hu/zip-api`

The ZIP API was created primarily for educational purposes and provides access to Hungarian counties, cities, and postal codes through a simple REST interface.

This service is intended for students, beginner developers, and anyone who would like to practice working with REST APIs. It can be used to learn and test common client-side and server-side development tasks, including:

- Sending HTTP requests
- Processing JSON responses
- Handling errors and validation
- Filtering and searching data
- Building API clients
- Working with asynchronous requests
- Implementing authenticated operations

Read-only endpoints are publicly accessible and do not require authentication. However, endpoints that create, update, or delete resources require authentication and are intended to demonstrate common authorization workflows used in real-world REST APIs.

The API is publicly available and designed specifically for learning, experimentation, and testing, providing realistic data and scenarios for REST API client development.
